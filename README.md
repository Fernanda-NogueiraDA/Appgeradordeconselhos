# Projeto: Gerador de Conselhos (Layout Responsivo)

Este é o layout de um gerador de conselhos desenvolvido como exercício de HTML e CSS.  
O foco foi construir uma interface responsiva e fiel ao design proposto, **sem uso de JavaScript**, utilizando apenas **HTML5 e CSS3**.

## 🧱 Estrutura

- `index.html`: Estrutura principal do card de conselhos.
- `style.css`: Estilos aplicados com unidades em `px` para maior controle visual.
- **Imagens utilizadas:**
  - `images/icon-dice.svg`
  - `images/pattern-divider-mobile.svg`
  - `images/pattern-divider-desktop.svg`

## ✨ Funcionalidades

- Layout centralizado verticalmente.
- Botão de dado flutuante, perfeitamente alinhado com o conteúdo.
- Divisor de conteúdo adaptável (mobile e desktop) via `<picture>`.
- Totalmente responsivo em telas menores (uso de `max-width`).
